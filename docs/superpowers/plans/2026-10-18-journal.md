# Cipherbook Journal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Journal to Cipherbook: typed parchment pages that stack per sitting, a free/snap wall, unique physical-looking pages, and sync to a Pi server that the desktop ingests into `~/knowledge/` + Qdrant.

**Architecture:** A Foundation-only SwiftPM package `JournalCore` (model, seeded appearance, wall layout, shuffle paths, pagination, sync merge) is tested on Linux. The iOS app layers a JSON-file store, a `WallRenderer`-based 2.5D renderer, a CoreText ruby page view, an editor, and a URLSession sync client on top. A standalone Flask+SQLite `journal-api` runs on the Pi; a desktop timer script pulls entries into markdown notes and daily backups.

**Tech Stack:** Swift 5.9 / SwiftUI / CoreText (iOS 16), SwiftPM, XcodeGen; Python 3.12 + Flask 3.1 + waitress + sqlite3 (server, desktop script); Docker for Linux test runs; GitHub Actions macOS CI.

**Spec:** `docs/superpowers/specs/2026-10-18-journal-design.md` (read its "Amendments from planning" section too).

## Global Constraints

- iOS deployment target **16.0**; Swift **5.9** language mode; no iOS 17+ APIs (no `@Observable`, no SwiftData, no `scrollPosition`).
- `JournalCore` is **Foundation-only** (no UIKit/SwiftUI/CoreGraphics) so `swift test` runs on Linux. Geometry uses its own `Pt`.
- Same seed + same preset ⇒ identical `PageLook` on every device. Never store rendered images; never sync anything but plain records.
- Seeds are `UInt64`, carried in records as **decimal strings**.
- Word art is **derived** from (page text, page `lookSeed`) with `WordArt.make`; it is never stored or synced, and uses the legacy vector table verbatim from `sbruschke/VectorCompression`.
- Device ids and server ids match `^[a-z0-9-]{1,64}$` (lowercase) so string ordering is identical in Swift, JS and Python.
- Sync is per-record last-write-wins: newer `updated_at` wins; ties go to the greater `updated_by` string; an exact replay is not newer.
- Deleting is a tombstone (`deleted: true`), never a row removal. The desktop never deletes notes because of a tombstone.
- Server: bearer token auth on everything except `/healthz`; max body 2 MB; max 500 changes per push; plaintext at rest (decided: same model as CarbBook).
- Backups: 30 daily + one per month indefinitely, on the Pi (inside `journal-api`) and on the desktop.
- Page splits are content: fonts/sizes never re-split pages; overflow draws shrink-to-fit (min 70%) then clips.
- Never claim an iOS-only task works until `build-ipa` CI is green; say so explicitly in the final report. Never commit to `main` directly: work on branch `journal`.
- Pi/Cloudflare/Pi-hole changes (Tasks 13) are outward-facing: confirm with the user before running them.

## Review Focus

1. **Seeds above 2^53** (e.g. `18446744073709551615`) must round-trip phone → server → desktop unchanged → tested in Task 4 (Codable) and Task 6 (server stores/returns strings verbatim).
2. **Emoji / ZWJ sequences / combining marks / a huge unbroken word** must never be cut mid-grapheme by pagination, and `pages.joined() == text` always → Task 3.
3. **Pressing Done on an empty or whitespace-only entry** must not leave an empty entry on the wall or the server → Task 7 (`JournalStore.finishEntry`).
4. **Two devices editing offline with identical `updated_at`** must converge on the same winner everywhere → Task 4 vectors, Task 6 server test.
5. **A page synced to a device with bigger fonts** must shrink/clip, never lose text or crash on zero-size layout → Task 10 (`fitScale` unit-tested in Core).
6. Wrong/missing bearer token → 401 with no data; oversized body → 413; malformed record → per-record `rejected`, rest of the batch still applied → Task 6.
7. Desktop note filenames from titles containing `/`, `..`, emoji or 300 chars; re-running the pull must be idempotent → Task 9.
8. **Pages whose text has no mappable characters** (emoji only, CJK) or thousands of words must give an empty/capped doodle quickly, never crash, and never leave art stuck from earlier text → Task 5a (`testEmptyAndUnmappable`, `testCapsWordsAndCharacters`).
9. **Wrap on, text starting beside/under the doodle:** a hard newline inside a narrow segment, a doodle spanning the whole text width, or a word wider than any free segment must neither loop forever nor drop text → Task 5a (`WrapGeometryTests`) and the `guardRows`/`n <= 0` guards in Task 8's `layout`.

```swift
import Foundation

/// Deterministic generator: the same seed yields the same sequence on every platform.
public struct SplitMix64: RandomNumberGenerator {
    private var state: UInt64

    public init(seed: UInt64) { state = seed }

    public mutating func next() -> UInt64 {
        state &+= 0x9E37_79B9_7F4A_7C15
        var z = state
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
        z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
        return z ^ (z >> 31)
    }

    /// Uniform in [0, 1).
    public mutating func unit() -> Double {
        Double(next() >> 11) / Double(UInt64(1) << 53)
    }

    public mutating func range(_ lo: Double, _ hi: Double) -> Double {
        lo + (hi - lo) * unit()
    }

    public mutating func int(_ r: ClosedRange<Int>) -> Int {
        r.lowerBound + Int(next() % UInt64(r.count))
    }
}

/// An independent seed for a sub-feature (stains, creases, fasteners …) of one page.
public func deriveSeed(_ seed: UInt64, _ salt: UInt64) -> UInt64 {
    var g = SplitMix64(seed: seed ^ (salt &* 0xD6E8_FEB8_6659_FD93))
    return g.next()
}
```

```swift
import Foundation

public struct Pt: Hashable, Codable {
    public var x: Double
    public var y: Double
    public init(_ x: Double, _ y: Double) { self.x = x; self.y = y }
}

public struct PresetStyle: Equatable {
    public let baseHex: String
    public let edgeHex: String
    public let inkHex: String
    /// 0 (pristine) … 1 (heavily worn): drives tears, stains and creases.
    public let wear: Double
}

public enum Preset: String, CaseIterable, Codable {
    case aged, vellum, linen, slate

    public var style: PresetStyle {
        switch self {
        case .aged:   return PresetStyle(baseHex: "#e6d3a3", edgeHex: "#a9824a", inkHex: "#3b2a1a", wear: 0.9)
        case .vellum: return PresetStyle(baseHex: "#f1e6c8", edgeHex: "#c9b27a", inkHex: "#2f2418", wear: 0.35)
        case .linen:  return PresetStyle(baseHex: "#ece6d8", edgeHex: "#b8ad94", inkHex: "#26313d", wear: 0.5)
        case .slate:  return PresetStyle(baseHex: "#2a2d33", edgeHex: "#14161a", inkHex: "#e8dfc9", wear: 0.6)
        }
    }
}

public struct Stain: Equatable { public var center: Pt; public var radius: Double; public var opacity: Double }
public struct Crease: Equatable { public var a: Pt; public var b: Pt; public var bend: Double; public var opacity: Double }
public struct Speckle: Equatable { public var at: Pt; public var radius: Double; public var opacity: Double }

public struct PageLook: Equatable {
    public static let edgePointsPerSide = 12

    /// Closed loop, clockwise from the top-left, in the unit square (edges wobble slightly outside/inside).
    public var outline: [Pt]
    public var stains: [Stain]
    public var creases: [Crease]
    public var speckles: [Speckle]
    /// Added to the base color's brightness, about ±0.06.
    public var brightness: Double
    /// Multiplies the nominal page width (0.97 … 1.03): pages differ slightly in shape.
    public var widthScale: Double
    /// Resting angle in degrees, ±2.5.
    public var rotation: Double
    /// Lift of each corner (TL, TR, BR, BL), 0…1, for the shadow/curl hint.
    public var cornerCurl: [Double]

    public static func make(seed: UInt64, preset: Preset) -> PageLook {
        let wear = preset.style.wear
        var edge = SplitMix64(seed: deriveSeed(seed, 1))
        var surface = SplitMix64(seed: deriveSeed(seed, 2))
        var shape = SplitMix64(seed: deriveSeed(seed, 3))

        let n = edgePointsPerSide
        // Smooth per-point wobble: raw noise averaged with its neighbours.
        let raw = (0..<(4 * n)).map { _ in edge.unit() }
        let amp = 0.004 + 0.010 * wear
        let wobble: [Double] = (0..<(4 * n)).map { i in
            let a = raw[(i + 4 * n - 1) % (4 * n)], b = raw[i], c = raw[(i + 1) % (4 * n)]
            return max(-0.01, ((a + b + c) / 3 - 0.35) * amp * 2)
        }

        // Tears: a triangular bite out of one edge.
        let tearCount = Int(edge.unit() * wear * 4)
        var tearBites = [Double](repeating: 0, count: 4 * n)
        for _ in 0..<tearCount {
            let side = edge.int(0...3)
            let center = edge.range(0.1, 0.9)
            let half = edge.range(0.06, 0.16)
            let depth = edge.range(0.015, 0.05) * (0.5 + wear)
            for i in 0..<n {
                let t = Double(i) / Double(n)
                let d = abs(t - center)
                if d < half { tearBites[side * n + i] += depth * (1 - d / half) }
            }
        }

        var outline: [Pt] = []
        for side in 0..<4 {
            for i in 0..<n {
                let t = Double(i) / Double(n)
                let base: Pt, inward: Pt
                switch side {
                case 0:  base = Pt(t, 0);     inward = Pt(0, 1)
                case 1:  base = Pt(1, t);     inward = Pt(-1, 0)
                case 2:  base = Pt(1 - t, 1); inward = Pt(0, -1)
                default: base = Pt(0, 1 - t); inward = Pt(1, 0)
                }
                let off = wobble[side * n + i] + tearBites[side * n + i]
                outline.append(Pt(base.x + inward.x * off, base.y + inward.y * off))
            }
        }

        let stainCount = Int(surface.unit() * (1 + wear * 5))
        let stains = (0..<stainCount).map { _ in
            Stain(center: Pt(surface.range(0.05, 0.95), surface.range(0.05, 0.95)),
                  radius: surface.range(0.04, 0.22),
                  opacity: surface.range(0.04, 0.16) * (0.5 + wear))
        }
        let creaseCount = Int(surface.unit() * (1 + wear * 3))
        let creases = (0..<creaseCount).map { _ in
            Crease(a: Pt(surface.range(0, 1), surface.range(0, 1)),
                   b: Pt(surface.range(0, 1), surface.range(0, 1)),
                   bend: surface.range(-0.08, 0.08),
                   opacity: surface.range(0.05, 0.2))
        }
        let speckles = (0..<Int(30 + 90 * wear)).map { _ in
            Speckle(at: Pt(surface.unit(), surface.unit()),
                    radius: surface.range(0.0015, 0.004),
                    opacity: surface.range(0.05, 0.25))
        }

        return PageLook(
            outline: outline, stains: stains, creases: creases, speckles: speckles,
            brightness: shape.range(-0.06, 0.06),
            widthScale: shape.range(0.97, 1.03),
            rotation: shape.range(-2.5, 2.5),
            cornerCurl: (0..<4).map { _ in shape.unit() * wear })
    }
}
```

`FastenerLook.swift`:
```swift
import Foundation

public enum FastenerKind: String, Codable, CaseIterable { case pin, staple, tape }

/// A fastener attached to a stack. The seed is a decimal string on the wire.
public struct Fastener: Codable, Equatable {
    public var kind: FastenerKind
    public var seed: String
    public init(kind: FastenerKind, seed: String) { self.kind = kind; self.seed = seed }
    public var seedValue: UInt64 { UInt64(seed) ?? 0 }
}

public struct FastenerLook: Equatable {
    /// Position on the top page in unit coordinates (y near the top edge).
    public var position: Pt
    public var angle: Double
    public var size: Double
    public var wear: Double

    public static func make(kind: FastenerKind, seed: UInt64) -> FastenerLook {
        var g = SplitMix64(seed: deriveSeed(seed, 11))
        switch kind {
        case .pin:
            return FastenerLook(position: Pt(g.range(0.42, 0.58), g.range(0.02, 0.07)),
                                angle: g.range(-12, 12), size: g.range(0.9, 1.1), wear: g.unit())
        case .staple:
            let left = g.unit() < 0.5
            return FastenerLook(position: Pt(left ? g.range(0.04, 0.12) : g.range(0.88, 0.96), g.range(0.02, 0.1)),
                                angle: left ? g.range(25, 55) : g.range(-55, -25), size: g.range(0.9, 1.1), wear: g.unit())
        case .tape:
            return FastenerLook(position: Pt(g.range(0.35, 0.65), g.range(0.0, 0.04)),
                                angle: g.range(-9, 9), size: g.range(0.9, 1.15), wear: g.unit())
        }
    }
}
```

```swift
@testable import JournalCore

final class PaginatorTests: XCTestCase {
    private func fits10(_ s: String) -> Bool { s.count <= 10 }

    func testEmptyTextIsOneEmptyPage() {
        XCTAssertEqual(Paginator.paginate("", fits: fits10), [""])
    }

    func testSplitsAtWordBoundariesAndIsLossless() {
        let pages = Paginator.paginate("hello world foo bar", fits: fits10)
        XCTAssertEqual(pages, ["hello ", "world foo ", "bar"])
        XCTAssertEqual(pages.joined(), "hello world foo bar")
    }

    func testShortTextIsOnePage() {
        XCTAssertEqual(Paginator.paginate("hi there", fits: fits10), ["hi there"])
    }

    func testHugeWordIsSplitByCharacters() {
        let word = String(repeating: "a", count: 25)
        let pages = Paginator.paginate(word, fits: fits10)
        XCTAssertEqual(pages.joined(), word)
        XCTAssertTrue(pages.allSatisfy { $0.count <= 10 })
        XCTAssertEqual(pages.count, 3)
    }

    func testNeverSplitsGraphemeClusters() {
        // Family emoji (ZWJ sequence), flag, e + combining acute: each is ONE Character.
        let text = String(repeating: "👨‍👩‍👧‍👦🇺🇸e\u{301}", count: 12)
        let pages = Paginator.paginate(text, fits: fits10)

        for p in pages { XCTAssertEqual(String(p).count, p.count) } // re-parse is stable
        XCTAssertTrue(pages.allSatisfy { $0.count <= 10 })
    }
```

```swift
import Foundation

public enum Paginator {
    /// Alternating runs of whitespace / non-whitespace, so breaks land between words.
    static func tokens(_ s: String) -> [String] {
        var out: [String] = []
        var cur = ""
        var curIsSpace: Bool?
        for ch in s {
            let isSpace = ch.isWhitespace
            if let c = curIsSpace, c != isSpace { out.append(cur); cur = "" }
            cur.append(ch)
            curIsSpace = isSpace
        }
        if !cur.isEmpty { out.append(cur) }
        return out
    }

    /// Splits `text` into pages that each satisfy `fits`, greedily. `fits` must be monotone
    /// (a prefix of a fitting string fits). The pages always concatenate back to `text`.
    public static func paginate(_ text: String, fits: (String) -> Bool) -> [String] {
        var toks = tokens(text)
        if toks.isEmpty { return [""] }
        var pages: [String] = []
        var i = 0
        while i < toks.count {
            // Largest k such that toks[i..<i+k] fits.
            var lo = 0, hi = toks.count - i
            while lo < hi {
                let mid = (lo + hi + 1) / 2
                if fits(toks[i..<(i + mid)].joined()) { lo = mid } else { hi = mid - 1 }
            }
            if lo > 0 {
                pages.append(toks[i..<(i + lo)].joined())
                i += lo
                continue
            }
            // Even the first token is too big: cut it by characters (at least one).
            let chars = Array(toks[i])
            var cl = 0, ch = chars.count
            while cl < ch {
                let mid = (cl + ch + 1) / 2
                if fits(String(chars[0..<mid])) { cl = mid } else { ch = mid - 1 }
            }
            let take = max(1, cl)
            pages.append(String(chars[0..<take]))
            if take < chars.count {
                toks[i] = String(chars[take...])
            } else {
                i += 1
            }
        }
        return pages
    }
}

/// Scale (≤ 1) that makes `contentHeight` fit in `available`, never below `minimum`.
public func fitScale(contentHeight: Double, available: Double, minimum: Double = 0.7) -> Double {
    guard contentHeight > 0 else { return 1 }
    if contentHeight <= available { return 1 }
    return max(minimum, available / contentHeight)
}
```

```swift
import Foundation

public struct RecordVersion: Equatable {
    public var updatedAt: Int64
    public var updatedBy: String
    public init(updatedAt: Int64, updatedBy: String) { self.updatedAt = updatedAt; self.updatedBy = updatedBy }
}

/// Last-write-wins: later timestamp wins; ties go to the greater device id (plain code-unit
/// comparison — device ids are restricted to [a-z0-9-] so every platform agrees). A replay isn't newer.
public func isNewer(_ incoming: RecordVersion, than stored: RecordVersion?) -> Bool {
    guard let stored else { return true }
    if incoming.updatedAt != stored.updatedAt { return incoming.updatedAt > stored.updatedAt }
    return incoming.updatedBy > stored.updatedBy
}

/// A pulled row replaces the local one unless the local row beats it.
public func shouldApplyPulled(incoming: RecordVersion, local: RecordVersion?) -> Bool {
    guard let local else { return true }
    return !isNewer(local, than: incoming)
}

public enum SyncRecord: Equatable {
    case entry(Entry)
    case page(Page)

    var table: String { if case .entry = self { return "entry" } else { return "page" } }
    var id: String { switch self { case .entry(let e): return e.id; case .page(let p): return p.id } }
    var version: RecordVersion {
        switch self {
        case .entry(let e): return RecordVersion(updatedAt: e.updatedAt, updatedBy: e.updatedBy)
        case .page(let p):  return RecordVersion(updatedAt: p.updatedAt, updatedBy: p.updatedBy)
        }
    }
}

public struct SyncChange: Codable, Equatable {
    public var record: SyncRecord
    public init(record: SyncRecord) { self.record = record }

    enum CodingKeys: String, CodingKey { case table, record }

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        switch try c.decode(String.self, forKey: .table) {
        case "entry": record = .entry(try c.decode(Entry.self, forKey: .record))
        case "page":  record = .page(try c.decode(Page.self, forKey: .record))
        default:
            throw DecodingError.dataCorruptedError(forKey: .table, in: c, debugDescription: "unknown table")
        }
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(record.table, forKey: .table)
        switch record {
        case .entry(let e): try c.encode(e, forKey: .record)
        case .page(let p):  try c.encode(p, forKey: .record)
        }
    }
}

public struct PushResult: Codable, Equatable {
    public var table: String
    public var id: String?
    /// "accepted" | "ignored" | "rejected"
    public var status: String
    public var serverSeq: Int64?
    public var reason: String?

    enum CodingKeys: String, CodingKey { case table, id, status, reason, serverSeq = "server_seq" }

    public init(table: String, id: String?, status: String, serverSeq: Int64?, reason: String?) {
        self.table = table; self.id = id; self.status = status; self.serverSeq = serverSeq; self.reason = reason
    }
}

public struct PullResponse: Codable, Equatable {
    public var changes: [SyncChange]
    public var next: Int64
    public var more: Bool
}

public extension JournalData {
    mutating func applyPulled(_ changes: [SyncChange]) {
        for change in changes {
            let rec = change.record
            switch rec {
            case .entry(let e):
                let local = entries[e.id].map { RecordVersion(updatedAt: $0.updatedAt, updatedBy: $0.updatedBy) }
                if shouldApplyPulled(incoming: rec.version, local: local) {
                    entries[e.id] = e
                    if local == nil || !isNewer(local!, than: rec.version) { pending.remove("entry/\(e.id)") }
                }
            case .page(let p):
                let local = pages[p.id].map { RecordVersion(updatedAt: $0.updatedAt, updatedBy: $0.updatedBy) }
                if shouldApplyPulled(incoming: rec.version, local: local) {
                    pages[p.id] = p
                    pending.remove("page/\(p.id)")
                }
            }
        }
    }

    /// Records still waiting for the server, entries first. Keys with no record are dropped.
    func pendingChanges(limit: Int) -> [SyncChange] {
        var out: [SyncChange] = []
        for key in pending.sorted() {
            let parts = key.split(separator: "/", maxSplits: 1).map(String.init)
            guard parts.count == 2 else { continue }
            if parts[0] == "entry", let e = entries[parts[1]] { out.append(SyncChange(record: .entry(e))) }
            if parts[0] == "page", let p = pages[parts[1]] { out.append(SyncChange(record: .page(p))) }
        }
        out.sort { ($0.record.table, $0.record.id) < ($1.record.table, $1.record.id) }
        return Array(out.prefix(limit))
    }

    /// Results are matched to the pushed changes by index. Accepted, ignored (the server already
    /// had a newer row) and rejected (retrying cannot help) all leave the pending set; a missing
    /// result keeps the record pending for the next sync.
    mutating func settle(pushed: [SyncChange], results: [PushResult]) {
        for (i, ch) in pushed.enumerated() where i < results.count {
            pending.remove("\(ch.record.table)/\(ch.record.id)")
        }
        let known = Set(pushed.map { "\($0.record.table)/\($0.record.id)" })
        pending = pending.filter { key in !known.contains(key) || pushed.enumerated().contains { i, c in
            "\(c.record.table)/\(c.record.id)" == key && i >= results.count } }
    }
}
```

```swift
import Foundation

public struct Cell: Hashable { public var col: Int; public var row: Int }

public enum WallLayout {
    public static let cellW = 260.0
    public static let cellH = 340.0

    public static func cell(for p: Pt) -> Cell {
        Cell(col: Int((p.x / cellW).rounded()), row: Int((p.y / cellH).rounded()))
    }

    public static func center(of c: Cell) -> Pt { Pt(Double(c.col) * cellW, Double(c.row) * cellH) }

    /// Nearest unoccupied cell to the exact point `p`, searching outward ring by ring.
    static func nearestFree(to p: Pt, occupied: Set<Cell>) -> Cell {
        let home = cell(for: p)
        if !occupied.contains(home) { return home }
        var best: (Cell, Double)?
        for ring in 1...64 {
            for row in (home.row - ring)...(home.row + ring) {
                for col in (home.col - ring)...(home.col + ring) {
                    guard max(abs(col - home.col), abs(row - home.row)) == ring else { continue }
                    let c = Cell(col: col, row: row)
                    if occupied.contains(c) { continue }
                    let ctr = center(of: c)
                    let d = (ctr.x - p.x) * (ctr.x - p.x) + (ctr.y - p.y) * (ctr.y - p.y)
                    if best == nil || d < best!.1 { best = (c, d) }     // row-major scan ⇒ stable ties
                }
            }
            if best != nil { return best!.0 }
        }
        return home
    }

    public static func snapAll(_ entries: [Entry]) -> [Entry] {
        var out = entries
        let order = entries.indices.filter { !entries[$0].deleted }
            .sorted { (entries[$0].createdAt, entries[$0].id) < (entries[$1].createdAt, entries[$1].id) }
        var occupied = Set<Cell>()
        for i in order {
            let p = Pt(entries[i].x, entries[i].y)
            let c = nearestFree(to: p, occupied: occupied)
            occupied.insert(c)
            let ctr = center(of: c)
            if out[i].freeX == nil { out[i].freeX = p.x; out[i].freeY = p.y }
            out[i].x = ctr.x; out[i].y = ctr.y
        }
        return out
    }

    public static func restoreAll(_ entries: [Entry]) -> [Entry] {
        entries.map { e in
            var e = e
            guard !e.deleted, let fx = e.freeX, let fy = e.freeY else { return e }
            e.x = fx; e.y = fy; e.freeX = nil; e.freeY = nil
            return e
        }
    }

    public static func drop(_ id: String, at p: Pt, snap: Bool, in entries: [Entry]) -> [Entry] {
        var out = entries
        guard let i = out.firstIndex(where: { $0.id == id && !$0.deleted }) else { return out }
        if snap {
            let occupied = Set(out.enumerated().filter { $0.offset != i && !$0.element.deleted }
                .map { cell(for: Pt($0.element.x, $0.element.y)) })
            let ctr = center(of: nearestFree(to: p, occupied: occupied))
            out[i].x = ctr.x; out[i].y = ctr.y
        } else {
            out[i].x = p.x; out[i].y = p.y
        }
        out[i].freeX = nil; out[i].freeY = nil
        return out
    }
}
```

```swift
import Foundation

/// One sample of a page being shuffled. `layer` is a step function: it applies from this
/// keyframe's `t` until the next one. `lift` (0…1) drives the shadow.
public struct ShuffleKeyframe: Equatable {
    public var t: Double
    public var offsetX: Double
    public var layer: Int
    public var lift: Double
}

public enum StackOps {
    /// `pages` bottom → top. Returns the same pages with `order` renumbered 0…n-1.
    public static func move(_ pages: [Page], from: Int, to: Int) -> [Page] {
        var list = pages.sorted { $0.order < $1.order }
        guard list.indices.contains(from), list.indices.contains(to), from != to else { return list }
        let p = list.remove(at: from)
        list.insert(p, at: to)
        for i in list.indices { list[i].order = i }
        return list
    }

    /// A page leaves the stack sideways *beneath* the pages above it, rises clear, changes layer
    /// only while fully outside the stack (`offsetX >= clearance`), then slides back in at its
    /// new layer. That is the physical rule: it never passes through pages it should be behind.
    public static func shufflePath(count: Int, from: Int, to: Int, clearance: Double) -> [ShuffleKeyframe] {
        guard count > 1, from != to, (0..<count).contains(from), (0..<count).contains(to) else { return [] }
        return [
            ShuffleKeyframe(t: 0.00, offsetX: 0,         layer: from, lift: 0),
            ShuffleKeyframe(t: 0.30, offsetX: clearance, layer: from, lift: 0),
            ShuffleKeyframe(t: 0.45, offsetX: clearance, layer: to,   lift: 1),
            ShuffleKeyframe(t: 0.60, offsetX: clearance, layer: to,   lift: 1),
            ShuffleKeyframe(t: 0.75, offsetX: clearance, layer: to,   lift: 0),
            ShuffleKeyframe(t: 1.00, offsetX: 0,         layer: to,   lift: 0),
        ]
    }
}
```

```swift
import Foundation

public enum EntryEditing {
    /// Re-paginates the edited page and everything after it. Earlier pages are untouched; pages
    /// whose text does not change keep their stamp (so they are not re-synced); new pages get a
    /// fresh id and look seed; pages no longer needed become tombstones.
    public static func reflow(pages: [Page], entryID: String, from index: Int, newText: String,
                              fits: (String) -> Bool, now: Int64, device: String,
                              makeID: () -> String, makeSeed: () -> UInt64) -> [Page] {
        var live = pages.filter { !$0.deleted }.sorted { $0.order < $1.order }
        let dead = pages.filter { $0.deleted }
        let idx = min(max(index, 0), max(live.count - 1, 0))
        let tail = newText + live.dropFirst(idx + 1).map(\.text).joined()
        let newTexts = Paginator.paginate(tail, fits: fits)

        var result: [Page] = Array(live.prefix(idx))
        for (j, text) in newTexts.enumerated() {
            let pos = idx + j
            if pos < live.count {
                var p = live[pos]
                if p.text != text || p.order != pos {
                    p.text = text; p.order = pos; p.updatedAt = now; p.updatedBy = device
                }
                result.append(p)
            } else {
                result.append(Page(id: makeID(), entryId: entryID, order: pos, text: text,
                                   lookSeed: String(makeSeed()), deleted: false, updatedAt: now, updatedBy: device))
            }
        }
        if live.count > idx + newTexts.count {
            for p in live[(idx + newTexts.count)...] {
                var t = p; t.deleted = true; t.updatedAt = now; t.updatedBy = device
                result.append(t)
            }
        }
        live.removeAll()
        return result + dead
    }
}
```

### Task 5a: Word art — the legacy vector visualizer as a per-page doodle

Source of truth: `sbruschke/VectorCompression` `docs/app.js` (`BASE_VECTORS`, `visualizeWord` with *Layer words* on and *Show individual vectors* on, no resultant arrow). Every word restarts at the origin; each character adds its fixed 3D vector tip-to-tail; later words are drawn denser (the original's red→black lightness ramp). Here the 3D chains are projected to 2D with a seeded camera angle and drawn as hand-inked strokes. The drawing is **derived** from (page text, page `lookSeed`) — never stored or synced — so every device draws the same doodle.

**Files:**
- Create: `Packages/JournalCore/Sources/JournalCore/LegacyVectors.swift`
- Create: `Packages/JournalCore/Sources/JournalCore/WordArt.swift`
- Test: `Packages/JournalCore/Tests/JournalCoreTests/WordArtTests.swift`

**Interfaces:**
- Consumes: `Pt`, `SplitMix64`, `deriveSeed` (Tasks 1–2).
- Produces:
  - `struct V3: Equatable { var x, y, z: Double }`, `enum LegacyVectors { static let vectors: [Character: V3] }` — the 93 entries of `BASE_VECTORS`, verbatim.
  - `struct WordArtStroke: Equatable { a, c, b: Pt` (quadratic Bézier, art space −0.5…0.5), `barbL, barbR: Pt?` (arrowhead ticks), `widthA, widthB: Double` (relative pen widths), `tone: Double` (0 = first word … 1 = last), `wordIndex: Int }`.
  - `struct WordArtDrawing: Equatable { strokes: [WordArtStroke]; center: Pt; size: Double; rotation: Double; var isEmpty: Bool; static let empty; func pagePoint(_ p: Pt) -> Pt }` — `pagePoint` maps art space to the page's unit square (accounting for the 240×320 page ratio and the rotation); the renderer must use it.
  - `struct PageRect: Equatable { var minX, minY, maxX, maxY: Double }` (page unit square), `struct WordArtPlacement: Equatable { center: Pt; size: Double; rotation: Double; var frame: PageRect }` — `frame` is the axis-aligned bounds of the rotated doodle *square* and depends on the seed only (never on the text), so text wrapping around it has no circular dependency.
  - `enum WrapGeometry { static func segments(top: Double, bottom: Double, width: Double, exclusion: PageRect?, minSegment: Double) -> [ClosedRange<Double>] }` — the horizontal free intervals of a text row band `[top,bottom]` in a box `[0,width]` once `exclusion` (same coordinate space as the box) is removed; segments narrower than `minSegment` are dropped; `[0...width]` when there is no exclusion or no vertical overlap; `[]` when the exclusion covers the whole row.
  - `enum WordArt { static func placement(seed: UInt64) -> WordArtPlacement; static let maxWords = 120; static let maxCharsPerWord = 30; static func splitWords(_ text: String) -> [String]; static func make(text: String, seed: UInt64) -> WordArtDrawing }`.
- Behaviour: characters with no legacy vector (accents, emoji, cipher private-use glyphs) are skipped, as in the original; a word with no mappable character is dropped; more than `maxWords` words are ignored; camera yaw/pitch and the doodle's page placement come from the seed only (so adding a word never spins the picture); each stroke's bend/width/arrowhead comes from `(seed, wordIndex, charIndex)` so editing a later word does not change earlier strokes' shapes; placement keeps every stroke point (including rotation) inside the page.

```swift
    public init(minX: Double, minY: Double, maxX: Double, maxY: Double) {

public struct WordArtPlacement: Equatable {
    public var center: Pt
    public var size: Double
    public var rotation: Double

    /// Axis-aligned bounds, in the page unit square, of the rotated doodle square.
    public var frame: PageRect {
        let d = WordArtDrawing(strokes: [], center: center, size: size, rotation: rotation)
        let corners = [Pt(-0.5, -0.5), Pt(0.5, -0.5), Pt(0.5, 0.5), Pt(-0.5, 0.5)].map(d.pagePoint)
        return PageRect(minX: corners.map(\.x).min()!, minY: corners.map(\.y).min()!,
                        maxX: corners.map(\.x).max()!, maxY: corners.map(\.y).max()!)
    }
}

public struct WordArtDrawing: Equatable {
    public var strokes: [WordArtStroke]
    /// Centre of the doodle in the page's unit square.
    public var center: Pt
    /// Width of the doodle as a fraction of the page width.
    public var size: Double
    /// Degrees.
    public var rotation: Double

    public var isEmpty: Bool { strokes.isEmpty }
    public static let empty = WordArtDrawing(strokes: [], center: Pt(0.5, 0.5), size: 0, rotation: 0)

    /// Art space (−0.5…0.5, square) → the page's unit square. The doodle is square in *points*
    /// (width = size × page width), so y is scaled by the 240:320 page ratio.
    public func pagePoint(_ p: Pt) -> Pt {
        let r = rotation * .pi / 180
        let x = p.x * size, y = p.y * size
        return Pt(center.x + x * cos(r) - y * sin(r),
                  center.y + (x * sin(r) + y * cos(r)) * WordArt.pageWidthOverHeight)
    }
}

public enum WordArt {
    public static let maxWords = 120
    public static let maxCharsPerWord = 30
    public static let pageWidthOverHeight = 240.0 / 320.0

    public static func splitWords(_ text: String) -> [String] {
        text.split(whereSeparator: { $0.isWhitespace }).map(String.init)
    }

    public static func make(text: String, seed: UInt64) -> WordArtDrawing {
        var chains: [[V3]] = []
        for w in splitWords(text) {
            let vs = w.compactMap { LegacyVectors.vectors[$0] }.prefix(maxCharsPerWord)
            if !vs.isEmpty { chains.append(Array(vs)) }
            if chains.count == maxWords { break }
        }
        guard !chains.isEmpty else { return .empty }

        // Camera: fixed per page, independent of the text, so typing never spins the picture.
        var cam = SplitMix64(seed: deriveSeed(seed, 21))
        let yaw = cam.range(0, 2 * .pi), pitch = cam.range(0.35, 1.2)
        func project(_ p: V3) -> Pt {
            let x1 = p.x * cos(yaw) + p.z * sin(yaw)
            let z1 = -p.x * sin(yaw) + p.z * cos(yaw)
            return Pt(x1, p.y * cos(pitch) - z1 * sin(pitch))
        }

        var strokes: [WordArtStroke] = []
        for (wi, chain) in chains.enumerated() {
            let tone = chains.count > 1 ? Double(wi) / Double(chains.count - 1) : 1
            var pos = V3(x: 0, y: 0, z: 0)
            for (ci, v) in chain.enumerated() {
                let next = V3(x: pos.x + v.x, y: pos.y + v.y, z: pos.z + v.z)
                let p0 = project(pos), p1 = project(next)
                pos = next
                let dx = p1.x - p0.x, dy = p1.y - p0.y
                let len = (dx * dx + dy * dy).squareRoot()
                if len < 1e-9 { continue }                 // vector points straight at the camera

                var g = SplitMix64(seed: deriveSeed(seed, 0x1000_0000 &+ (UInt64(wi) << 16) &+ UInt64(ci)))
                let bend = g.range(-0.12, 0.12) * len
                let c = Pt((p0.x + p1.x) / 2 - dy / len * bend, (p0.y + p1.y) / 2 + dx / len * bend)
                let widthA = g.range(0.9, 1.5)
                let widthB = widthA * g.range(0.55, 0.85)

                var hx = p1.x - c.x, hy = p1.y - c.y
                let hl = (hx * hx + hy * hy).squareRoot()
                if hl < 1e-9 { hx = dx / len; hy = dy / len } else { hx /= hl; hy /= hl }
                let barbLen = len * g.range(0.16, 0.24)
                let th = g.range(18, 32) * .pi / 180
                let bx = -hx, by = -hy
                func rot(_ a: Double) -> Pt { Pt(bx * cos(a) - by * sin(a), bx * sin(a) + by * cos(a)) }
                let l = rot(th), r = rot(-th)
                strokes.append(WordArtStroke(
                    a: p0, c: c, b: p1,
                    barbL: Pt(p1.x + l.x * barbLen, p1.y + l.y * barbLen),
                    barbR: Pt(p1.x + r.x * barbLen, p1.y + r.y * barbLen),
                    widthA: widthA, widthB: widthB, tone: tone, wordIndex: wi))
            }
        }
        guard !strokes.isEmpty else { return .empty }

        // Fit the whole picture into the −0.5…0.5 square, preserving aspect.
        var pts: [Pt] = []
        for s in strokes { pts += [s.a, s.c, s.b] + [s.barbL, s.barbR].compactMap { $0 } }
        let minX = pts.map(\.x).min()!, maxX = pts.map(\.x).max()!
        let minY = pts.map(\.y).min()!, maxY = pts.map(\.y).max()!
        let extent = max(maxX - minX, maxY - minY)
        guard extent > 1e-9 else { return .empty }
        let cx = (minX + maxX) / 2, cy = (minY + maxY) / 2
        func norm(_ p: Pt) -> Pt { Pt((p.x - cx) / extent, (p.y - cy) / extent) }
        strokes = strokes.map { s in
            var s = s
            s.a = norm(s.a); s.c = norm(s.c); s.b = norm(s.b)
            s.barbL = s.barbL.map(norm); s.barbR = s.barbR.map(norm)
            return s
        }

        let pl = placement(seed: seed)
        return WordArtDrawing(strokes: strokes, center: pl.center, size: pl.size, rotation: pl.rotation)
    }

    /// Where the doodle sits: anywhere on the page such that even a 25° rotation stays on it.
    /// Depends on the seed only, so the text can wrap around the same frame before a word is typed.
    public static func placement(seed: UInt64) -> WordArtPlacement {
        var pl = SplitMix64(seed: deriveSeed(seed, 22))
        let size = pl.range(0.26, 0.42)
        let rotation = pl.range(-25, 25)
        let hxm = 0.67 * size + 0.02
        let hym = 0.67 * size * pageWidthOverHeight + 0.02
        return WordArtPlacement(center: Pt(pl.range(hxm, 1 - hxm), pl.range(hym, 1 - hym)),
                                size: size, rotation: rotation)
    }
}
```

```swift
import Foundation

public enum WrapGeometry {
    public static func segments(top: Double, bottom: Double, width: Double, exclusion: PageRect?,
                                minSegment: Double) -> [ClosedRange<Double>] {
        guard let e = exclusion, bottom > e.minY, top < e.maxY else { return width > 0 ? [0...width] : [] }
        var out: [ClosedRange<Double>] = []
        let leftEnd = min(width, max(0, e.minX)), rightStart = max(0, min(width, e.maxX))
        if leftEnd - 0 >= minSegment { out.append(0...leftEnd) }
        if width - rightStart >= minSegment { out.append(rightStart...width) }
        return out
    }
}
```

```python
from datetime import date

def keep_set(dates: list, daily: int = 30) -> set:
    """Newest `daily` dates, plus the newest date of every calendar month (kept forever)."""
    ordered = sorted(set(dates))
    keep = set(ordered[-daily:]) if daily > 0 else set()
    newest_in_month = {}
    for d in ordered:
        newest_in_month[(d.year, d.month)] = d
    return keep | set(newest_in_month.values())
```

```python
def db() -> sqlite3.Connection:
    pathlib.Path(DB_PATH).parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(DB_PATH, timeout=30)
    conn.row_factory = sqlite3.Row

        CREATE INDEX IF NOT EXISTS records_seq ON records(seq);
        CREATE TABLE IF NOT EXISTS meta (seq INTEGER NOT NULL);

def _is_int(v) -> bool:
    return isinstance(v, int) and not isinstance(v, bool)


def _is_num(v) -> bool:
    return isinstance(v, (int, float)) and not isinstance(v, bool)


def validate(table, rec) -> str | None:
    """Returns None if valid, else a reason ('unknown_table' | 'invalid')."""
    if table not in ("entry", "page"):
        return "unknown_table"
    if not isinstance(rec, dict):
        return "invalid"
    if not (isinstance(rec.get("id"), str) and ID_RE.match(rec["id"])):
        return "invalid"
    if not (_is_int(rec.get("updated_at")) and rec["updated_at"] >= 0):
        return "invalid"
    if not (isinstance(rec.get("updated_by"), str) and DEV_RE.match(rec["updated_by"])):
        return "invalid"
    if not isinstance(rec.get("deleted"), bool):
        return "invalid"
    if table == "entry":
        if not _is_int(rec.get("created_at")):
            return "invalid"
        for k in ("x", "y", "rot"):
            if not _is_num(rec.get(k)):
                return "invalid"
        for k in ("free_x", "free_y"):
            if rec.get(k) is not None and not _is_num(rec[k]):
                return "invalid"
        if rec.get("title") is not None and not (isinstance(rec["title"], str) and len(rec["title"]) <= 500):
            return "invalid"
        fs = rec.get("fasteners")
        if not isinstance(fs, list) or len(fs) > 20:
            return "invalid"
        for f in fs:
            if not (isinstance(f, dict) and f.get("kind") in ("pin", "staple", "tape")
                    and isinstance(f.get("seed"), str) and SEED_RE.match(f["seed"])):
                return "invalid"
    else:
        if not (isinstance(rec.get("entry_id"), str) and ID_RE.match(rec["entry_id"])):
            return "invalid"
        if not (_is_int(rec.get("ord")) and 0 <= rec["ord"] < 100_000):
            return "invalid"
        if not (isinstance(rec.get("text"), str) and len(rec["text"]) <= MAX_PAGE_TEXT):
            return "invalid"
        if not (isinstance(rec.get("look_seed"), str) and SEED_RE.match(rec["look_seed"])):
            return "invalid"
    return None


def newer(inc_at, inc_by, st_at, st_by) -> bool:
    if inc_at != st_at:
        return inc_at > st_at
    return inc_by > st_by

@app.post("/sync/push")
def push():
    body = request.get_json(silent=True)
    if not isinstance(body, dict) or not isinstance(body.get("changes"), list):
        return jsonify(error="bad body"), 400
    changes = body["changes"]
    if len(changes) > MAX_CHANGES:
        return jsonify(error="too many changes"), 400
    results = []
    conn = db()
    try:
        for ch in changes:
            table = ch.get("table") if isinstance(ch, dict) else None
            rec = ch.get("record") if isinstance(ch, dict) else None
            why = validate(table, rec)
            rid = rec.get("id") if isinstance(rec, dict) and isinstance(rec.get("id"), str) else None
            if why:
                results.append({"table": table, "id": rid, "status": "rejected", "server_seq": None, "reason": why})
                continue
            row = conn.execute("SELECT updated_at, updated_by FROM records WHERE tbl=? AND id=?",
                               (table, rec["id"])).fetchone()
            if row and not newer(rec["updated_at"], rec["updated_by"], row["updated_at"], row["updated_by"]):
                results.append({"table": table, "id": rec["id"], "status": "ignored", "server_seq": None, "reason": None})
                continue
            conn.execute("UPDATE meta SET seq = seq + 1")
            seq = conn.execute("SELECT seq FROM meta").fetchone()[0]
            conn.execute(
                "INSERT INTO records (tbl,id,seq,updated_at,updated_by,body) VALUES (?,?,?,?,?,?) "
                "ON CONFLICT(tbl,id) DO UPDATE SET seq=excluded.seq, updated_at=excluded.updated_at, "
                "updated_by=excluded.updated_by, body=excluded.body",
                (table, rec["id"], seq, rec["updated_at"], rec["updated_by"], json.dumps(rec, separators=(",", ":"))))
            results.append({"table": table, "id": rec["id"], "status": "accepted", "server_seq": seq, "reason": None})
        conn.commit()
    finally:
        conn.close()
    return jsonify(results=results)


@app.get("/sync/pull")
def pull():
    try:
        since = max(0, int(request.args.get("since", "0")))
        limit = min(1000, max(1, int(request.args.get("limit", "500"))))
    except ValueError:
        return jsonify(error="bad params"), 400
    conn = db()
    try:
        rows = conn.execute("SELECT tbl, seq, body FROM records WHERE seq > ? ORDER BY seq LIMIT ?",
                            (since, limit + 1)).fetchall()
    finally:
        conn.close()
    more = len(rows) > limit
    rows = rows[:limit]
    changes = [{"table": r["tbl"], "record": json.loads(r["body"])} for r in rows]
    nxt = rows[-1]["seq"] if rows else since
    return jsonify(changes=changes, next=nxt, more=more)


def make_backup() -> str:
    """SQLite online backup into BACKUP_DIR/journal-YYYY-MM-DD.db (overwrites today's)."""
    BACKUP_DIR.mkdir(parents=True, exist_ok=True)
    name = f"journal-{date.today().isoformat()}.db"
    tmp = BACKUP_DIR / (name + ".tmp")
    src, dst = db(), sqlite3.connect(tmp)
    try:
        src.backup(dst)
    finally:
        dst.close(); src.close()
    os.replace(tmp, BACKUP_DIR / name)
    return name


def prune_backups() -> None:
    files = {}
    for p in BACKUP_DIR.glob("journal-*.db"):
        try:
            files[date.fromisoformat(p.stem.removeprefix("journal-"))] = p
        except ValueError:
            continue
    keep = retention.keep_set(list(files), daily=30)
    for d, p in files.items():
        if d not in keep:
            p.unlink()


@app.get("/backup/latest")
def backup_latest():
    files = sorted(BACKUP_DIR.glob("journal-*.db")) if BACKUP_DIR.exists() else []
    if not files:
        return Response("no backup yet", 404)
    latest = files[-1]
    return Response(latest.read_bytes(), mimetype="application/octet-stream",
                    headers={"X-Backup-Name": latest.name})


def _backup_loop():
    last = None
    while True:
        now = datetime.now()
        if now.hour >= BACKUP_HOUR and last != now.date():
            try:
                log.info("backup %s", make_backup()); prune_backups(); last = now.date()
            except Exception:
                log.exception("backup failed")
        time.sleep(300)


if __name__ == "__main__":

        raise SystemExit("JOURNAL_TOKEN is required")
```

```swift
import Foundation
import JournalCore

@MainActor
final class JournalStore: ObservableObject {
    @Published private(set) var data: JournalData
    private let file = Storage.journalDir.appendingPathComponent("journal.json")
    private var saveWork: DispatchWorkItem?

    init() {
        if let raw = try? Data(contentsOf: file), let d = try? JSONDecoder().decode(JournalData.self, from: raw) {
            data = d
        } else {
            data = JournalData(deviceID: "ios-" + UUID().uuidString.lowercased().prefix(24))
            save()
        }
    }

    private var now: Int64 { Int64(Date().timeIntervalSince1970 * 1000) }
    private var device: String { data.deviceID }

    var liveEntries: [Entry] {
        data.entries.values.filter { !$0.deleted }.sorted { ($0.createdAt, $0.id) < ($1.createdAt, $1.id) }
    }

    func pages(of entryID: String) -> [Page] { data.livePages(of: entryID) }

    // MARK: persistence
    private func save() {
        saveWork?.cancel()
        let snapshot = data
        let work = DispatchWorkItem { [file] in
            if let raw = try? JSONEncoder().encode(snapshot) { try? raw.write(to: file, options: .atomic) }
        }
        saveWork = work
        DispatchQueue.global(qos: .utility).asyncAfter(deadline: .now() + 0.4, execute: work)
    }

    private func touch(entry e: Entry) { var e = e; e.updatedAt = now; e.updatedBy = device; put(e) }
    private func put(_ e: Entry) {
        data.entries[e.id] = e; data.pending.insert("entry/\(e.id)"); save()
    }
    private func put(_ p: Page) {
        data.pages[p.id] = p; data.pending.insert("page/\(p.id)"); save()
    }

    // MARK: entries
    @discardableResult
    func newEntry() -> String {
        let id = UUID().uuidString.lowercased()
        let live = liveEntries
        // Drop new stacks to the right of the rightmost one, on the same row.
        let x = (live.map(\.x).max() ?? -WallLayout.cellW) + WallLayout.cellW
        var rng = SystemRandomNumberGenerator()
        let e = Entry(id: id, createdAt: now, title: nil, x: x, y: 0,
                      rot: Double.random(in: -3...3, using: &rng), freeX: nil, freeY: nil,
                      fasteners: [Fastener(kind: .pin, seed: String(UInt64.random(in: 0...UInt64.max)))],
                      deleted: false, updatedAt: now, updatedBy: device)
        put(e)
        let p = Page(id: UUID().uuidString.lowercased(), entryId: id, order: 0, text: "",
                     lookSeed: String(UInt64.random(in: 0...UInt64.max)),
                     deleted: false, updatedAt: now, updatedBy: device)
        put(p)
        return id
    }

    /// Replaces page `pageIndex` with `text` and re-flows it and the pages after it.
    func edit(entryID: String, pageIndex: Int, text: String, fits: (String) -> Bool) {
        let all = data.pages.values.filter { $0.entryId == entryID }
        let out = EntryEditing.reflow(pages: all, entryID: entryID, from: pageIndex, newText: text, fits: fits,
                                      now: now, device: device,
                                      makeID: { UUID().uuidString.lowercased() },
                                      makeSeed: { UInt64.random(in: 0...UInt64.max) })
        for p in out where data.pages[p.id] != p { put(p) }
    }

    /// Done: an entry with no text at all is discarded entirely (never synced, never shown).
    func finishEntry(_ id: String) {
        let live = pages(of: id)
        if live.allSatisfy({ $0.text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty }) {
            discard(id)
        }
    }

    private func discard(_ id: String) {
        for p in data.pages.values where p.entryId == id {
            data.pages[p.id] = nil; data.pending.remove("page/\(p.id)")
        }
        data.entries[id] = nil; data.pending.remove("entry/\(id)")
        save()
    }

    func deleteEntry(_ id: String) {
        guard var e = data.entries[id] else { return }
        for var p in data.pages.values where p.entryId == id && !p.deleted {
            p.deleted = true; p.updatedAt = now; p.updatedBy = device; put(p)
        }
        e.deleted = true; touch(entry: e)
    }

    // MARK: wall
    func setSnap(_ on: Bool) {
        let before = data.entries
        let list = Array(data.entries.values)
        let after = on ? WallLayout.snapAll(list) : WallLayout.restoreAll(list)
        for e in after where before[e.id] != e { touch(entry: e) }
    }

    func drop(_ id: String, at p: Pt, snap: Bool) {
        let before = data.entries
        let after = WallLayout.drop(id, at: p, snap: snap, in: Array(data.entries.values))
        for e in after where before[e.id] != e { touch(entry: e) }
    }

    func reorder(entryID: String, from: Int, to: Int) {
        for p in StackOps.move(pages(of: entryID), from: from, to: to) where data.pages[p.id]?.order != p.order {
            var p = p; p.updatedAt = now; p.updatedBy = device; put(p)
        }
    }

    func addFastener(_ kind: FastenerKind, to id: String) {
        guard var e = data.entries[id] else { return }
        e.fasteners.append(Fastener(kind: kind, seed: String(UInt64.random(in: 0...UInt64.max))))
        touch(entry: e)
    }

    func removeFastener(at index: Int, from id: String) {
        guard var e = data.entries[id], e.fasteners.indices.contains(index) else { return }
        e.fasteners.remove(at: index); touch(entry: e)
    }

    // MARK: sync plumbing (used by JournalSyncClient)
    func pending(limit: Int) -> [SyncChange] { data.pendingChanges(limit: limit) }
    func settle(pushed: [SyncChange], results: [PushResult]) { data.settle(pushed: pushed, results: results); save() }
    func applyPull(_ changes: [SyncChange], next: Int64) {
        data.applyPulled(changes); data.cursor = next; save()
    }
}
```

- [ ] **Step 2: `Render25D.swift`** — draws the outline as a smooth closed path (midpoint quadratic smoothing), fills with base color + brightness, overlays stains (radial gradients), creases (stroked quad curves), speckles (small circles) via `Canvas`, strokes the edge with `edgeHex` at low opacity, adds the shadow driven by `lift`, and rotates by `look.rotation`.
```swift
import SwiftUI
import JournalCore

struct Render25D: WallRenderer {
    func page(_ s: PageRenderSpec) -> AnyView { AnyView(ParchmentPage(spec: s)) }
    func fastener(_ s: FastenerRenderSpec) -> AnyView { AnyView(FastenerShape(spec: s)) }
}

private func smoothPath(_ pts: [Pt], in size: CGSize) -> Path {
    var path = Path()
    guard pts.count > 2 else { return path }
    let p = pts.map { CGPoint(x: $0.x * size.width, y: $0.y * size.height) }
    let mid = { (a: CGPoint, b: CGPoint) in CGPoint(x: (a.x + b.x) / 2, y: (a.y + b.y) / 2) }
    path.move(to: mid(p[p.count - 1], p[0]))
    for i in 0..<p.count { path.addQuadCurve(to: mid(p[i], p[(i + 1) % p.count]), control: p[i]) }
    path.closeSubpath()
    return path
}

private func shade(_ hex: String, by delta: Double) -> Color {
    let ui = UIColor(Color(hex: hex))
    var h: CGFloat = 0, sat: CGFloat = 0, b: CGFloat = 0, a: CGFloat = 0
    ui.getHue(&h, saturation: &sat, brightness: &b, alpha: &a)
    return Color(hue: Double(h), saturation: Double(sat), brightness: min(1, max(0, Double(b) + delta)))
}

struct ParchmentPage: View {
    let spec: PageRenderSpec

    var body: some View {
        let w = spec.size.width * spec.look.widthScale, h = spec.size.height
        let size = CGSize(width: w, height: h)
        let base = shade(spec.style.baseHex, by: spec.look.brightness)
        let edge = Color(hex: spec.style.edgeHex)
        ZStack {
            Canvas { ctx, sz in
                let outline = smoothPath(spec.look.outline, in: sz)
                ctx.fill(outline, with: .linearGradient(
                    Gradient(colors: [base, shade(spec.style.baseHex, by: spec.look.brightness - 0.05)]),
                    startPoint: .zero, endPoint: CGPoint(x: sz.width, y: sz.height)))
                ctx.clip(to: outline)
                for st in spec.look.stains {
                    let c = CGPoint(x: st.center.x * sz.width, y: st.center.y * sz.height)
                    let r = st.radius * sz.width
                    ctx.fill(Path(ellipseIn: CGRect(x: c.x - r, y: c.y - r, width: r * 2, height: r * 2)),
                             with: .radialGradient(Gradient(colors: [edge.opacity(st.opacity), edge.opacity(0)]),
                                                   center: c, startRadius: 0, endRadius: r))
                }
                for cr in spec.look.creases {
                    var p = Path()
                    let a = CGPoint(x: cr.a.x * sz.width, y: cr.a.y * sz.height)
                    let b = CGPoint(x: cr.b.x * sz.width, y: cr.b.y * sz.height)
                    p.move(to: a)
                    p.addQuadCurve(to: b, control: CGPoint(x: (a.x + b.x) / 2 + cr.bend * sz.width,
                                                           y: (a.y + b.y) / 2 + cr.bend * sz.height))
                    ctx.stroke(p, with: .color(edge.opacity(cr.opacity)), lineWidth: 0.8)
                }
                for sp in spec.look.speckles {
                    let r = sp.radius * sz.width
                    ctx.fill(Path(ellipseIn: CGRect(x: sp.at.x * sz.width - r, y: sp.at.y * sz.height - r,
                                                    width: r * 2, height: r * 2)),
                             with: .color(edge.opacity(sp.opacity)))
                }
                if let art = spec.art, !art.isEmpty {
                    let inkUI = UIColor(spec.ink), edgeUI = UIColor(edge)
                    func pt(_ p: Pt) -> CGPoint {
                        let q = art.pagePoint(p); return CGPoint(x: q.x * sz.width, y: q.y * sz.height)
                    }
                    for s in art.strokes {
                        // Early words lean toward the paper's edge-ink, later ones toward the writing ink
                        // (the original's red→black ramp), denser as the page goes on.
                        let color = Color(uiColor: edgeUI.mix(inkUI, s.tone))
                            .opacity((0.28 + 0.4 * s.tone) * spec.artStrength)
                        var p = Path()
                        p.move(to: pt(s.a)); p.addQuadCurve(to: pt(s.b), control: pt(s.c))
                        if let l = s.barbL, let r = s.barbR { p.move(to: pt(l)); p.addLine(to: pt(s.b)); p.addLine(to: pt(r)) }
                        ctx.stroke(p, with: .color(color),
                                   style: StrokeStyle(lineWidth: (s.widthA + s.widthB) * 0.55, lineCap: .round, lineJoin: .round))
                    }
                }
                // Darker rim, like old paper edges.
                ctx.stroke(outline, with: .color(edge.opacity(0.55)), lineWidth: 2.2)
            }
            .frame(width: w, height: h)

            RubyPageText(text: spec.text, mainFont: spec.mainFont, subFont: spec.subFont,
                         ink: UIColor(spec.ink), size: CGSize(width: w * 0.84, height: h * 0.86),
                         exclusion: spec.exclusion.map {
                             CGRect(x: $0.minX * w - 0.08 * w, y: $0.minY * h - 0.07 * h,
                                    width: ($0.maxX - $0.minX) * w, height: ($0.maxY - $0.minY) * h)
                         })
                .frame(width: w * 0.84, height: h * 0.86)
        }
        .frame(width: w, height: h)
        .rotationEffect(.degrees(spec.look.rotation))
        .shadow(color: .black.opacity(0.28 + 0.12 * spec.lift), radius: 2 + spec.lift * 14, x: 0, y: 1 + spec.lift * 9)
    }
}

private extension UIColor {
```

- [ ] **Step 3: `RubyPageText.swift`** — one CoreText layout shared by pagination (`fits`) and drawing, built on `CTTypesetter` so lines are placed in the free segments of each row (square text wrap, like an inline image with text around it). Single-font: `mainFont`; dual-font: each word gets a `CTRubyAnnotation` (`.center`, `.after`) in `subFont`.
```swift
import SwiftUI
import CoreText
import JournalCore

struct RubyPageText: UIViewRepresentable {
    var text: String
    var mainFont: UIFont
    var subFont: UIFont?
    var ink: UIColor
    var size: CGSize
    /// Text-box points (origin top-left); nil ⇒ text spans the full width.
    var exclusion: CGRect? = nil

    func makeUIView(context: Context) -> RubyView { let v = RubyView(); v.isOpaque = false; v.backgroundColor = .clear; return v }
    func updateUIView(_ v: RubyView, context: Context) {
        v.text = text; v.mainFont = mainFont; v.subFont = subFont; v.ink = ink; v.exclusion = exclusion; v.setNeedsDisplay()
    }

    static func attributed(_ text: String, main: UIFont, sub: UIFont?, ink: UIColor) -> NSAttributedString {
        let base: [NSAttributedString.Key: Any] = [.font: main, .foregroundColor: ink]
        guard let sub else { return NSAttributedString(string: text, attributes: base) }
        let out = NSMutableAttributedString()
        var cursor = text.startIndex
        for range in wordRanges(in: text) {
            if cursor < range.lowerBound { out.append(NSAttributedString(string: String(text[cursor..<range.lowerBound]), attributes: base)) }
            let word = String(text[range])
            var attrs = base
            let subAttrs: [CFString: Any] = [kCTFontAttributeName: sub, kCTForegroundColorAttributeName: ink.cgColor]
            attrs[NSAttributedString.Key(kCTRubyAnnotationAttributeName as String)] =
                CTRubyAnnotationCreateWithAttributes(.center, .auto, .after, word as CFString, subAttrs as CFDictionary)
            out.append(NSAttributedString(string: word, attributes: attrs))
            cursor = range.upperBound
        }
        if cursor < text.endIndex { out.append(NSAttributedString(string: String(text[cursor...]), attributes: base)) }
        return out
    }

    /// Runs of non-whitespace — the same notion of "word" the reader's sub font uses.
    static func wordRanges(in s: String) -> [Range<String.Index>] {
        var out: [Range<String.Index>] = []; var start: String.Index?
        for i in s.indices {
            if s[i].isWhitespace { if let st = start { out.append(st..<i); start = nil } }
            else if start == nil { start = i }
        }
        if let st = start { out.append(st..<s.endIndex) }
        return out
    }

    struct PlacedLine { let line: CTLine; let x: CGFloat; let baseline: CGFloat }   // baseline measured down from the top

    /// Lays the text out row by row. In each row the free segments (box minus `exclusion`) are filled
    /// left to right, so text reads across both sides of the doodle in order. A hard newline ends the row.
    static func layout(_ a: NSAttributedString, width: CGFloat, exclusion: CGRect?) -> (lines: [PlacedLine], height: CGFloat) {
        let ts = CTTypesetterCreateWithAttributedString(a)
        let length = a.length
        let ns = a.string as NSString
        let ex = exclusion.map { PageRect(minX: Double($0.minX), minY: Double($0.minY), maxX: Double($0.maxX), maxY: Double($0.maxY)) }
        var lines: [PlacedLine] = []
        var idx = 0, y: CGFloat = 0
        var guardRows = 0
        func metrics(_ l: CTLine) -> (asc: CGFloat, desc: CGFloat, lead: CGFloat) {
            var asc: CGFloat = 0, desc: CGFloat = 0, lead: CGFloat = 0
            _ = CTLineGetTypographicBounds(l, &asc, &desc, &lead)
            return (asc, desc, lead)
        }
        while idx < length, guardRows < 10_000 {
            guardRows += 1
            // Probe the row height with a full-width line.
            let probeCount = max(1, CTTypesetterSuggestLineBreak(ts, idx, Double(width)))
            let m = metrics(CTTypesetterCreateLine(ts, CFRange(location: idx, length: probeCount)))
            var rowAsc = m.asc, rowDesc = m.desc + m.lead
            let segs = WrapGeometry.segments(top: Double(y), bottom: Double(y + rowAsc + rowDesc), width: Double(width),
                                             exclusion: ex, minSegment: Double(max(24, rowAsc * 2)))
            if segs.isEmpty {                      // the doodle fills this row: skip below it
                y = max(y + 1, CGFloat(ex?.maxY ?? Double(y) + 1)); continue
            }
            var rowLines: [(CTLine, CGFloat)] = []
            for seg in segs where idx < length {
                var n = CTTypesetterSuggestLineBreak(ts, idx, seg.upperBound - seg.lowerBound)
                if n <= 0 { n = 1 }
                let line = CTTypesetterCreateLine(ts, CFRange(location: idx, length: n))
                let lm = metrics(line)
                rowAsc = max(rowAsc, lm.asc); rowDesc = max(rowDesc, lm.desc + lm.lead)
                rowLines.append((line, CGFloat(seg.lowerBound)))
                let endsRow = ns.character(at: idx + n - 1) == 0x0A
                idx += n
                if endsRow { break }
            }
            for (l, x) in rowLines { lines.append(PlacedLine(line: l, x: x, baseline: y + rowAsc)) }
            y += rowAsc + rowDesc
        }
        return (lines, y)
    }

    /// Pagination predicate: does `text` fit one page at this size/fonts (and around `exclusion`)?
    static func fits(_ text: String, main: UIFont, sub: UIFont?, size: CGSize, exclusion: CGRect? = nil) -> Bool {
        layout(attributed(text, main: main, sub: sub, ink: .black), width: size.width, exclusion: exclusion).height <= size.height
    }

    final class RubyView: UIView {
        var text = "", ink = UIColor.black
        var mainFont = UIFont.systemFont(ofSize: 18)
        var subFont: UIFont?
        var exclusion: CGRect?

        override func draw(_ rect: CGRect) {
            guard let ctx = UIGraphicsGetCurrentContext(), bounds.width > 1, bounds.height > 1, !text.isEmpty else { return }
            let a = RubyPageText.attributed(text, main: mainFont, sub: subFont, ink: ink)
            let natural = RubyPageText.layout(a, width: bounds.width, exclusion: exclusion).height
            let scale = CGFloat(fitScale(contentHeight: Double(natural), available: Double(bounds.height)))
            // Overflow: shrink (≥ 70 %) by laying out in a proportionally larger box, then scaling down.
            let inv = 1 / scale
            let ex = exclusion.map { CGRect(x: $0.minX * inv, y: $0.minY * inv, width: $0.width * inv, height: $0.height * inv) }
            let laid = RubyPageText.layout(a, width: bounds.width * inv, exclusion: ex)
            ctx.saveGState()
            ctx.scaleBy(x: scale, y: scale)
            ctx.textMatrix = CGAffineTransform(scaleX: 1, y: -1)               // UIKit is y-down; CoreText is y-up
            for p in laid.lines {
                ctx.textPosition = CGPoint(x: p.x, y: p.baseline)
                CTLineDraw(p.line, ctx)
            }
            ctx.restoreGState()
        }
    }
}
```
`ParchmentPage` converts `spec.exclusion` (page units) into the text box's points: with page size `(w, h)` and the text box `0.84w × 0.86h` centred, `CGRect(x: ex.minX*w - 0.08*w, y: ex.minY*h - 0.07*h, width: (ex.maxX-ex.minX)*w, height: (ex.maxY-ex.minY)*h)`, and passes it as `exclusion:`.
```python
#!/usr/bin/env python3
"""Pull Cipherbook journal entries from journal-api into ~/knowledge/journal/*.md, ingest them
into the KB, and keep a daily copy of the server's SQLite backup (30 daily + monthly forever).

Config: ~/.config/journal/server (URL), ~/.config/journal/token (chmod 600).
Idempotent: the note filename ends in the first 8 chars of the entry id; re-running rewrites
the same file. A deleted (tombstoned) entry never deletes an existing note.
"""
from __future__ import annotations

import json
import os
import pathlib
import re
import subprocess
import sys
import unicodedata
import urllib.request
from datetime import date, datetime
from zoneinfo import ZoneInfo

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent))
import retention  # noqa: E402


def slug(text: str) -> str:
    s = unicodedata.normalize("NFKD", text).encode("ascii", "ignore").decode().lower()
    s = re.sub(r"[^a-z0-9]+", "-", s).strip("-")
    return s[:40].strip("-")


def _yaml_str(s: str) -> str:
    return '"' + s.replace("\\", "\\\\").replace('"', '\\"') + '"'


def render_note(entry: dict, pages: list, tz) -> tuple:
    when = datetime.fromtimestamp(entry["created_at"] / 1000, tz)
    short = re.sub(r"[^a-z0-9]", "", entry["id"].lower())[:8]
    title = (entry.get("title") or "").strip()
    stem = slug(title) or when.strftime("%H%M")
    name = f"{when.date().isoformat()}-{stem}-{short}.md"
    body = "\n\n".join(p["text"].strip() for p in sorted(pages, key=lambda p: p["ord"]) if p["text"].strip())
    shown = title or "Journal " + when.strftime("%Y-%m-%d %H:%M")
    text = (
        "---\n"
        f"title: {_yaml_str(shown)}\n"
        "source: Cipherbook journal\n"
        f"date: {when.date().isoformat()}\n"
        "domain: personal\n"
        "project: cipherbook-journal\n"
        "tags: [journal]\n"
        "---\n\n"
        f"{body}\n"
    )
    return name, text


def http_fetch(base_url: str, token: str):
    def fetch(path: str):
        req = urllib.request.Request(base_url.rstrip("/") + path, headers={"Authorization": f"Bearer {token}"})
        try:
            with urllib.request.urlopen(req, timeout=60) as r:
                return r.status, dict(r.headers), r.read()
        except urllib.error.HTTPError as e:
            return e.code, {}, b""
    return fetch


def run(base_url, token, notes_dir, state_dir, backup_dir, ingest, tz, fetch, today=None):
    notes_dir, state_dir, backup_dir = map(pathlib.Path, (notes_dir, state_dir, backup_dir))
    for d in (notes_dir, state_dir, backup_dir):
        d.mkdir(parents=True, exist_ok=True)
    today = today or date.today()
    cursor_file = state_dir / "cursor"
    cursor = int(cursor_file.read_text().strip()) if cursor_file.exists() else 0

    entries, pages = {}, {}
    more = True
    while more:
        status, _, raw = fetch(f"/sync/pull?since={cursor}&limit=500")
        if status != 200:
            raise SystemExit(f"pull failed: HTTP {status}")
        body = json.loads(raw)
        for ch in body["changes"]:
            rec = ch["record"]
            (entries if ch["table"] == "entry" else pages)[rec["id"]] = rec
        cursor, more = body["next"], body["more"]

    # Entries touched by this pull — including ones whose only change was a page — need re-rendering.
    touched = {e["id"] for e in entries.values()} | {p["entry_id"] for p in pages.values()}
    if touched:
        # Pull the full state of touched entries (cursor 0 pull is cheap for a personal journal).
        status, _, raw = fetch("/sync/pull?since=0&limit=1000")
        full = json.loads(raw)
        all_entries = {c["record"]["id"]: c["record"] for c in full["changes"] if c["table"] == "entry"}
        all_pages = [c["record"] for c in full["changes"] if c["table"] == "page"]
        for eid in touched:
            e = all_entries.get(eid) or entries.get(eid)
            if not e or e["deleted"]:
                continue
            live = [p for p in all_pages if p["entry_id"] == eid and not p["deleted"]]
            if not live:
                continue
            name, text = render_note(e, live, tz)
            path = notes_dir / name
            if not path.exists() or path.read_text() != text:
                path.write_text(text)
                ingest(path)
    cursor_file.write_text(f"{cursor}\n")

    status, headers, data = fetch("/backup/latest")
    if status == 200:
        name = headers.get("X-Backup-Name", f"journal-{today.isoformat()}.db")
        if re.fullmatch(r"journal-\d{4}-\d{2}-\d{2}\.db", name):
            (backup_dir / name).write_bytes(data)
    files = {}
    for p in backup_dir.glob("journal-*.db"):
        try:
            files[date.fromisoformat(p.stem.removeprefix("journal-"))] = p
        except ValueError:
            pass
    keep = retention.keep_set(list(files), daily=30)
    for d, p in files.items():
        if d not in keep:
            p.unlink()


def main():
    cfg = pathlib.Path.home() / ".config/journal"
    base = (cfg / "server").read_text().strip()
    token = (cfg / "token").read_text().strip()
    kb_ingest = lambda p: subprocess.run(["kb-ingest", str(p)], check=False)
    run(base, token, pathlib.Path.home() / "knowledge/journal",
        pathlib.Path.home() / ".local/state/journal-pull", pathlib.Path.home() / "backups/journal",
        kb_ingest, ZoneInfo(os.environ.get("TZ", "America/Chicago")), http_fetch(base, token))


if __name__ == "__main__":
    main()
```

- [ ] **Step 1: `JournalSyncClient.swift`** — push-then-pull loop; pushes `store.pending(limit: 200)` until empty or an error, then pulls from `store.data.cursor` until `more == false`. All HTTP via `URLSession`; bearer from `settings.token`; 401 ⇒ "Check your token in Journal settings"; no token/URL ⇒ returns "Sync not configured" without a request.
```swift
import Foundation
import JournalCore

@MainActor
enum JournalSyncClient {
    static func sync(store: JournalStore, settings: JournalSettings) async -> String {
        guard let base = URL(string: settings.serverURL.trimmingCharacters(in: .whitespaces)), !settings.token.isEmpty
        else { return "Sync not configured" }
        func request(_ path: String, method: String = "GET", body: Data? = nil) -> URLRequest {
            var r = URLRequest(url: URL(string: path, relativeTo: base)!.absoluteURL)
            r.httpMethod = method; r.httpBody = body; r.timeoutInterval = 30
            r.setValue("Bearer \(settings.token)", forHTTPHeaderField: "Authorization")
            if body != nil { r.setValue("application/json", forHTTPHeaderField: "Content-Type") }
            return r
        }
        do {
            var pushed = 0
            while true {
                let batch = store.pending(limit: 200)
                if batch.isEmpty { break }
                let (data, resp) = try await URLSession.shared.data(
                    for: request("/sync/push", method: "POST", body: JSONEncoder().encode(PushBody(changes: batch))))
                if let h = resp as? HTTPURLResponse, h.statusCode == 401 { return "Check your token in Journal settings" }
                guard let h = resp as? HTTPURLResponse, h.statusCode == 200 else { return "Server error while pushing" }
                let results = try JSONDecoder().decode(PushReply.self, from: data).results
                store.settle(pushed: batch, results: results)
                pushed += batch.count
                if results.count < batch.count { break }
            }
            var pulled = 0
            while true {
                let (data, resp) = try await URLSession.shared.data(
                    for: request("/sync/pull?since=\(store.data.cursor)&limit=500"))
                guard let h = resp as? HTTPURLResponse, h.statusCode == 200 else { return "Server error while pulling" }
                let page = try JSONDecoder().decode(PullResponse.self, from: data)
                store.applyPull(page.changes, next: page.next)
                pulled += page.changes.count
                if !page.more { break }
            }
            return "Synced · sent \(pushed), received \(pulled)"
        } catch {
            return "Offline — will retry (\(error.localizedDescription))"
        }
    }

    private struct PushBody: Encodable { let changes: [SyncChange] }
    private struct PushReply: Decodable { let results: [PushResult] }
}
```
